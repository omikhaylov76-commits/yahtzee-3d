Реализуй ранее согласованный план. Если плана ещё не было — сначала остановись и
попроси прогнать /plan-feature.

Уточнение/ограничение на эту итерацию (опционально): $ARGUMENTS

Правила реализации:
- Делай ТОЛЬКО то, что в согласованном плане. Не расширяй область, не «причёсывай заодно».
- Следуй конвенциям из `CLAUDE.md`. Не нарушай решения из `docs/adr/`.
- Иди маленькими шагами; если по ходу всплыло незапланированное решение — остановись и спроси.
- Не добавляй новые зависимости без моего согласия.
- Секреты — только через переменные окружения, не в коде.
- Закончив кусок: запусти линт и тесты (командами из `CLAUDE.md`) и сообщи результат.
- НЕ коммить сам — это сделаю я / отдельной командой /commit.
- В конце покажи краткое резюме изменений и предложи мне посмотреть `git diff`.
