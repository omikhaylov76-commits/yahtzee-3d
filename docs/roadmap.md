- [ ] **F5. Звук** — `SoundEngine` (Howler), маппинг доменных событий → звуки, эмбиент,

- [ ] **F6. Сочность и полировка** — частицы/блик на Yahtzee, микроанимации (фикс, запись,

      60fps, fallback без WebGL.

## Backlog / хвосты

- reduced-motion + 3D: сейчас reduce-motion НЕ переключает в 2D (3D — ядро впечатления);
  деликатная обработка — оставить 3D, но делать бросок мгновенным/без тумбла (F6).
- Физику падения костей «попилить» позже: дошлифовать кувырок в воздухе/качение по столу и
  естественность доводки на грань (детерминированная доводка предсказателя — местами можно
  натуральнее). Базовое поведение принято заказчиком (F4).
- Бандл вырос до ~3 МБ (Three.js + Rapier WASM) — разбить на чанки/ленивую загрузку (F6).
- 5 npm-уязвимостей в транзитивных dev-зависимостях — проверить `npm audit`, закрыть без
  ломающих обновлений.
- Джокер: строгое принуждение бокса (сначала верхний по достоинству) не enforced в ядре —
  запись свободная, счёт корректный. Возможное уточнение правил позже.
