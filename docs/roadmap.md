# Roadmap — Yahtzee 3D

> Вехи и фичи. Статусы: todo / in-progress / done / cancelled.

## Веха 1 — Красивый играбельный локальный вариант (hotseat 1–4)

merged: no

- [x] **F0. Скелет** — Vite + TS + React + R3F поднимаются: сцена с кубиком на столе и
      кнопка. «hello world end-to-end». (c3c1bdc; см. docs/progress/done/skeleton.md)
- [x] **F1. Ядро правил и счёта** (чистый TS + тесты) — типы `GameState`, RNG, `reduce`,
      13 категорий, верхний бонус, бонусные Yahtzee, джокер, конец игры/победитель. 34 теста
      Vitest. Без UI/3D. (2a21085, 3f26e55, 516d1ce; docs/progress/done/f1-core.md)
- [ ] **F2. Transport + Storage + стор** — `Transport` (LocalTransport), `NetworkTransport`
      заглушка, `GameStorage` (localStorage, автосохранение/восстановление), Zustand-мост.
- [ ] **F3. Игровой UI без 3D** — экраны старт/игра/победитель, таблица 13 категорий с
      превью очков, контролы (Roll, hold по клику в списке, запись), состояния (ход/броски/
      недоступно/загрузка/ошибка). Кости пока простые (плейсхолдер), чтобы пройти полный матч.
- [ ] **F4. 3D-кости и физический бросок** — R3F-сцена, материалы/свет/тени в стиле Auros,
      Rapier-физика, приземление на значения ядра, фиксация кликом по кубику, считывание
      «успокоились». Замена плейсхолдера костей из F3.
- [ ] **F5. Звук** — `SoundEngine` (Howler), маппинг доменных событий → звуки, эмбиент,
      вкл/выкл + громкость. Свободные по лицензии ассеты (источник — в ADR/architecture).
- [ ] **F6. Сочность и полировка** — частицы/блик на Yahtzee, микроанимации (фикс, запись,
      смена игрока, победа), переходы экранов, финальная адаптивность и доступность, проверка
      60fps, fallback без WebGL.

_Порядок намеренный: сначала играбельная логика (F1–F3), потом красота (F4–F6) поверх неё._
