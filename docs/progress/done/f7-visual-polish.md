Последний коммит по фиче: c9b25ba (под-шаг 3)
Файлы под-шага (тронем): по под-шагам ниже (каждый под-шаг = свой коммит)

Решения заказчика (старт F7):

- Делаем правки 1, 2, 3, 4 из дизайн-разбора. №5 (атмосфера/искры на фоне) — НЕ делаем.
- НЕ трогаем: 3D-кости (арена/физика) и подсветку доступных категорий F6.5 — они уже хороши,
  новые акценты строим ВОКРУГ них.
- Грунт — `docs/design-refs/auros-DESIGN.md`: добираем недоиспользованное (экстремальный display
  с тугим минус-трекингом, перламутровый Aurora-градиент, точка-маркер у секций, щедрые отступы).
- Заказчик смотрит каждый под-шаг вживую и может попросить «ярче/тусклее/толще/тоньше».

Сквозной принцип: только подача (CSS + лёгкая разметка), правил/ядра/счёта не касаемся. Дисциплина
Auros: радиусы 6/16, teal→cyan только на главном действии, lilac/Aurora — дозированно, веса 400–600.

## Под-шаги:

- [x] 1. (bd30b68) Терминальная шапка хода — крупный тугой display + живой счёт игрока
  - Тронем: `src/ui/screens/GameScreen.tsx` (вывести суммарный счёт активного игрока через
    `totalsFor` из scoreView), `src/ui/theme.css` (`.turn`, `.turn__name`, новый `.turn__total`).
  - НЕ тронем: ядро/render3d/звук, score-table, F6.5, кости.
  - Поведение: имя текущего игрока крупнее и туже (до ~60–72px desktop, tracking ≈ −0.04em); рядом —
    живой `total` мономерной цифрой (Space Mono) с мягким свечением, обновляется при записи. Мотив
    Auros «торговый терминал / данные-созвездия».
  - Граничные: длинное имя (ограничить/ellipsis, как в таблице); счёт 0 в начале партии; узкий
    экран (clamp размеров, перенос имя/счёт); не конкурировать с костями-героем (счёт тише имени).
  - Проверка: build + lint; dev — имя крупное/тугое, рядом счёт, меняется после записи; узкий экран
    не ломается; число tabular-nums не «прыгает».

- [x] 2. (50b9f41) Скорборд — иерархия и фирменный мотив в таблице очков
  - Тронем: `src/ui/components/ScoreTable.tsx` (точка-маркер у «Upper»/«Lower», подача строки Total

  - НЕ тронем: `CategoryRow` превью-логику (F6.5), ядро/счёт.
  - Поведение: 6px teal-точка (фирменный pip) у заголовков секций; строка Total визуально весомее
    (крупнее/ярче, тонкая верхняя линия accent); верхний бонус читаемее — прогресс к 63 понятным
    текстом/мини-полоской вместо сухого «45/63»; разделители строк легче (не сплошной hairline на
    каждой — например, только под секциями/итогом).
  - Граничные: бонус достигнут (+35) vs прогресс; 1–4 игрока (сетка колонок не ломается); узкий экран.
  - Проверка: build + lint; dev — секции с точкой, Total выделен, бонус читаем; 4 игрока — сетка цела.

- [-] 3. ОТКАЧЕНО (по фидбэку). Aurora-кромка (c9b25ba) убрана: читалась как случайная цветная
  черта, а не премиальный край. Кромка-хейрлайн — НЕ канонический способ Auros (по DESIGN.md
  Aurora-градиент = ghost/secondary CTA, не линия). Возможная будущая опция — Aurora на
  вторичной кнопке (Nudge / «New game»), но осторожно (легко выглядит крикливо). Сейчас — без неё.
  - Тронем: `src/ui/theme.css` (токен `--grad-aurora` + тонкая 1px перламутровая кромка по верху
    карточки таблицы `.board`/`.score-table` через `::before`).
  - НЕ тронем: ничего, кроме одного места (принцип «одна смелость в одном месте»).
  - Поведение: иридесцентный `#cbfffc→#edfffe→#fffdfa→#fad1ff` тонкой линией только наверху карточки —
    «премиальный край», которого больше нигде нет. Статичный (без анимации) → reduced-motion ок.
  - Граничные: не перекрывает контент/радиус карточки; ровно одно место; не на главной кнопке (там
    teal→cyan).
  - Проверка: build + lint; dev — тонкая перламутровая кромка вверху таблицы и больше нигде.
