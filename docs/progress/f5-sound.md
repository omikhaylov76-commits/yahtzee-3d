## Решение (согласовано на старте F5)

- **Путь A — процедурный звук через Web Audio API** (без ассетов/лицензий, без новой
  зависимости). Реальные CC0-сэмплы — в backlog, добавим позже за тем же интерфейсом
  `SoundEngine`. Зафиксировать в **ADR 0006**.
- Цель — «дорого/тепло»: мягкие огибающие (плавная атака/затухание), фильтрованные тембры,
  лёгкая реверберация (ConvolverNode с процедурным impulse response) для глубины, умеренная
  громкость. Не «пищалки».

## Контракт (architecture.md, уже заложен)

```ts
interface SoundEngine {
  play(event: SoundEvent): void;
  setMuted(m: boolean): void;
  setVolume(v: number): void; // 0..1
  startAmbient(): void;
  stopAmbient(): void;
}
```

- Слой звука подписывается на доменные события ядра (через стор-мост) и НЕ лезет в правила.
- AudioContext создаётся/возобновляется по пользовательскому жесту (политика автоплея).

## Дизайн звуков (процедурно)

- **dice** (бросок/удар): глуховатый объёмный «тук» — низкий резонансный тон (~150–220 Гц) +
  короткий фильтрованный шум, lowpass, лёгкий питч-разброс; на бросок — серия из нескольких
  «туков» (раскат) + реверб. Не электронный щелчок.
- **hold / release**: мягкий «поп»/клик — короткий тон с питч-блипом (вверх/вниз), мягкая
  атака, lowpass.
- **score**: благородный «динь» — колокольный тон (фундамент + пара негармоничных партиалов),
  мягкая атака, долгое затухание, реверб.
- **yahtzee**: восходящий аккорд/мини-фанфара (пентатоника/мажор), радостно, не резко.
- **win**: красивый победный мажорный аккорд (тоника+терция+квинта+октава), тёплый, сустейн.
- **turn**: тихий мягкий свуш — фильтрованный шум с разверткой bandpass.
- **denied**: деликатный низкий «нельзя» (тихий приглушённый блип).
- **ambient** (опц.): низкий медленно эволюционирующий пэд (детюн-осцилляторы + медленная
  модуляция фильтра), тихо, выключаемо.

## Маппинг событий ядра → звук

`dice:rolled→dice` · `die:held→hold` · `die:released→release` · `score:written→score` ·
`combo:yahtzee→yahtzee` · `turn:changed→turn` · `game:over→win` · `action:denied→denied`.
Подписка — эффект на `store.events` (1 раз на действие).
