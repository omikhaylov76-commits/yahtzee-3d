## План под-шага 2.L.b — Локальный соло-рекорд (+ развод localStorage)

**Цель.** Выполнить обещание spec (сценарий 11, ADR-0014): в соло-режиме (1 игрок) хранить
**персональный рекорд** — лучший итог между сессиями, локально, без аккаунта/сети. Показать его
на экране итогов соло («Final score»): «★ New personal record» при побитии, иначе «Personal best: N».

**Про «развод localStorage».** Сейчас он уже соблюдён ФАКТИЧЕСКИ: `GameStorage` (сохранение
партии) использует только `LocalTransport`; сетевого транспорта ещё нет. Жёсткое правило
«`NetworkTransport` НЕ использует `GameStorage`» естественно ляжет в **2.1.c** (когда пишем
сетевой транспорт) — отдельную работу под несуществующую сеть здесь НЕ делаем (без оверинжиниринга).
Соло-рекорд — тоже локальный концерн, отдельный ключ; сетевая статистика (ADR-0008) к нему не
относится. Зафиксируем это комментариями со ссылкой на ADR-0014.

**Хранилище рекорда.** Новый маленький модуль по образцу `LocalStorageGameStorage`:
версионированный ключ `yahtzee3d:v1:solo-record`, инъекцируемый `Storage` (для тестов), все
операции в try/catch (приватный режим/квота не роняют игру).

- `load(): number | null` — текущий рекорд или null.
- `record(total): { best: number; isRecord: boolean }` — если рекорда нет или `total > best`:
  сохранить и вернуть `{ best: total, isRecord: true }`; иначе `{ best, isRecord: false }`.
  Идемпотентно: повтор с тем же/меньшим итогом ничего не меняет (перезагрузка на экране
  итогов не «накручивает» рекорд).

**Файлы — ТРОНЕМ:**

- NEW `src/storage/soloRecordStorage.ts` — `SoloRecordStorage` (load/record, версионный ключ).
- NEW `src/storage/soloRecord.test.ts` — тесты (round-trip, нет ключа → null, повреждено → null,
  обновляет только при бо́льшем, первый результат = рекорд, недоступный storage не падает).
- EDIT `src/ui/screens/WinnerScreen.tsx` — в соло-ветке один раз на маунте вызвать `record(total)`
  и показать строку рекорда; мультиплеер не трогаем.
- EDIT `src/ui/theme.css` — стиль строки рекорда (сдержанный, сиреневый-дозированно для «New record»).
- EDIT `docs/progress/2L-local-mode.md` — отметки прогресса.

**Файлы — НЕ трогаем:** `src/core/*`, `src/transport/*` (LocalTransport уже локален),
`src/storage/GameStorage.ts`/`localStorageGameStorage.ts`/`memoryGameStorage.ts`,
`src/state/*`, `App.tsx`, остальные экраны/компоненты.

**Контракты/данные:** ядро/транспорт не меняем. Новый локальный ключ хранилища (отдельный от
ключа партии). **Новых зависимостей нет.**

**Граничные случаи:**

- Только соло (1 игрок). Мультиплеер — рекорд не считаем/не показываем.
- Первый соло-результат = рекорд (рекорда ещё не было).
- Перезагрузка на экране итогов → `record` идемпотентен (итог не больше сохранённого → без изменений).
- Недоступный/приватный localStorage → не падаем, рекорд просто не сохраняется (как и партия).
- a11y: строка рекорда — текст; англ. строки; reduced-motion наследуется.

**Как проверим (живьём, с артефактами):**

1. `npm run lint` — вывод.
2. `npm run test` — новые тесты `soloRecord.test.ts` + старые не падают (вывод).
3. Демо-скрипт (node, без сервера): прогнать `SoloRecordStorage.record()` на серии итогов
   (напр. 180 → 210 → 200) и показать реальный вывод `{best,isRecord}` — рекорд растёт только вверх.
4. `npm run build` — вывод (tsc + vite).
5. `npm run dev` → соло-партия до конца: на «Final score» видно строку рекорда; описать/скрин.
   (Полный соло-проход вручную — на заказчике; автоматические доказательства — тесты + демо.)

## План под-шага 2.L.a — Меню + роутер по режиму

**Цель.** Явная точка входа (ADR-0014): экран-меню «Yahtzee 3D» с выбором
**Play local (hotseat / solo)** vs **Play online**. Роутер начинает учитывать режим, а не
только состояние игры. Веха 1 (hotseat/соло, автосохранение-восстановление) НЕ ломается.
Онлайн-путь пока ведёт на заглушку «coming soon» (реальный онлайн — 2.0+/2.2).

**Дизайн (Auros + находки F8).** Тёмный океан Auros (та же палитра/шрифты/глубина из
`theme.css`). Дисплейный заголовок (`.display`), eyebrow с pip. Две **тактильные объёмные
кнопки** режима по лекалу F8 (глубина: `inset` блик сверху + жёсткая нижняя кромка
`0 2px 0 rgba(0,0,0,..)`, продавливание `translateY` при нажатии). Главная — Play local
(teal→cyan градиент), вторичная — Play online (поверхность + кромка). Луминесцентный ореол
за заголовком (как `.start__head::before`).

**Модель навигации.** Новый маленький UI-стор `src/state/uiStore.ts` (zustand, по образцу
`gameStore`): `view: 'menu' | 'localSetup' | 'online'` + `setView`. Навигация ОТДЕЛЕНА от
`gameStore` (тот — мост к transport/ядру, навигацию туда не мешаем). Сюда же будут добавляться
онлайн-виды (лобби/кабинет/лидерборд) в 2.2+.

**Роутинг (`App.tsx`).**

- не готово → `LoadingScreen` (как сейчас);
- **есть состояние игры** (`state` != null): `over` → `WinnerScreen`, иначе `GameScreen`
  — то есть активная/сохранённая локальная партия РЕЗЮМИТСЯ как в Вехе 1 (промис автосейва цел);
- иначе (партии нет) — по `view`: `menu` → `MenuScreen`, `localSetup` → `StartScreen`,
  `online` → `OnlineComingSoon`.

**Файлы — ТРОНЕМ:**

- NEW `src/state/uiStore.ts` — навигационный стор (`view`, `setView`).
- NEW `src/ui/screens/MenuScreen.tsx` — экран-меню (hero + 2 кнопки режима).
- NEW `src/ui/screens/OnlineComingSoon.tsx` — заглушка онлайна + «← Back».
- EDIT `src/App.tsx` — роутинг по режиму (резюм игры → иначе по `view`).
- EDIT `src/ui/screens/StartScreen.tsx` — кнопка «← Back» в меню (`setView('menu')`).
- EDIT `src/ui/screens/WinnerScreen.tsx` — «New game» → `reset()` + `setView('menu')`
  (после партии возвращаемся в меню, а не на setup); «Play again» (локальный) без изменений.
- EDIT `src/ui/theme.css` — стили меню, тактильных кнопок режима, заглушки, кнопки Back.

**Файлы — НЕ трогаем:** `src/core/*`, `src/transport/*`, `src/storage/*`,
`src/state/gameStore.ts`, `src/render3d/*`, `src/sound/*`, остальные компоненты.

**Контракты/данные:** изменений в ядре/транспорте/хранилище НЕТ. Навигация — чистый UI.
**Зависимости:** новых НЕТ. **localStorage:** в этом под-шаге НЕ трогаем (развод хранилища — 2.L.b).

**Граничные случаи:**

- Перезагрузка во время локальной партии → резюм в `GameScreen` (Веха 1 цела), меню не мешает.
- После победы: «Play again» → локальная новая партия; «New game» → `reset` + меню.
- Возврат из `StartScreen`/`OnlineComingSoon` в меню кнопкой Back.
- a11y: кнопки/ссылки фокусируемы, `aria`, видимый фокус (общий `:focus-visible`); строки на
  английском. reduced-motion — наследуется (общий гейт в `theme.css`).

**Как проверим (живьём, с артефактами):**

1. `npm run lint` — вывод.
2. `npm run build` — вывод (tsc + vite).
3. `npm run test` — существующие тесты не падают (UI-навигация ядро не трогает).
4. `npm run dev` → открыть: видно **Menu**; «Play local» → StartScreen → старт → Game;
   «Play online» → заглушка → Back; перезагрузка в партии → резюм. **Скриншот меню** заказчику.

Хвосты / спящие баги: нет
