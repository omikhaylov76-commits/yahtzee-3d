# f3-ui (фича в roadmap: Веха 1 → F3. Игровой UI без 3D)

Последний коммит по фиче: нет
Файлы под-шага (тронем): src/ui/\*\* (новое), src/App.tsx (переделать в роутер экранов),
src/main.tsx (импорт темы). Ядро/transport/стор (src/core, src/transport, src/state) — НЕ меняем,
только потребляем через useGameStore. 3D-сцена (src/scene/Scene.tsx) на F3 отложена,
вернётся в F4.

Цель F3: первый ИГРАБЕЛЬНЫЙ интерфейс (без 3D-физики, кости — DOM-плейсхолдеры с точками).
Полный матч проходится мышью и с клавиатуры: старт → игра → победитель. Стиль Auros,
скилл frontend-design против шаблонного вида.

## Дизайн-план (frontend-design)

Заземление: «мир» игры — кости (точки-pips), карточка счёта как «манифест/ведомость»,
Auros-идентичность «биолюминесцентная обсерватория данных» (тёмный океан + светящиеся
данные). Бриф фиксирует Auros — следуем его DESIGN.md (docs/design-refs/auros-DESIGN.md).

**Палитра (Auros):**

- `--bg` #012624 (Abyssal Teal) · `--surface` #011d1c · `--surface-2` #003734
- `--text` #bbc7c6 (Fog Veil) · `--heading` #ffffff · `--ice` #edfffe
- `--grad-primary` linear-gradient(90deg,#00827c,#cbfffc) — ТОЛЬКО кнопка Roll
- `--lilac` #fde9ff — дозированно: Yahtzee и победа

**Типографика (2+ роли, характерные, не дефолтные):**

- Display — **Space Grotesk** (геометрический гротеск с характером, тугой трекинг — в духе
  Matter из Auros). Заголовки, имена игроков.
- Body — **Inter** (нейтральный текст, подписи).
- Data — **Space Mono** (табличные цифры очков — «терминал данных» Auros), tabular-nums.
- Шрифты через Google Fonts <link> в index.html (фолбэк system-ui без сети).

**Layout:**

```
Desktop:                              Mobile:
┌───────────────┬──────────────┐      ┌──────────────┐
│  DICE ARENA   │  SCORE        │      │  player/turn │
│  (5 костей)   │  MANIFEST     │      │  DICE ARENA  │
│  Roll + pips  │  13 категорий │      │  Roll + pips │
│  чей ход      │  превью/итоги │      │  SCORE (tabs │
└───────────────┴──────────────┘      │  по игрокам) │
                                       └──────────────┘
```

**Signature (один запоминающийся элемент):** точка-pip как сквозной структурный мотив —
(1) eyebrow-метки с 6px светящейся точкой (правило Auros), (2) счётчик бросков как 3 pips
(заполнены = израсходованы), (3) на Yahtzee — биолюминесцентное «цветение» (bloom) акцентом.
Вокруг — тишина и дисциплина (тон, не тени; радиусы 6px контролы / 16px карточки).

## Граничные случаи

- 1 игрок (соло): экран победителя = «итог/рекорд», без «vs».
- Имена: пустое → плейсхолдер «Player N»; обрезка длины; повторяющиеся имена допустимы.
- Недоступные действия: Roll после 3-го броска, запись в занятую, действия не в свой «ход» —
  кнопки/строки визуально неактивны + мягкий отклик на попытку.
- Восстановление партии (F2): при загрузке стор уже может иметь phase=playing → сразу Game.
- Нет 3D на F3 — это норма; экран ошибки/fallback по-настоящему важен в F4 (WebGL).
- prefers-reduced-motion: отключить «цветение»/тряску, оставить статичные состояния.

## Как проверим (живая проверка)

- `npm run dev` — поднять, пройти полный матч 2 игроков от старта до победителя (привести
  лог старта + подтвердить, что экраны переключаются; по возможности скриншоты/described).
- `npm run build` + `npm run lint` + `npm run test` — чисто/зелено.
- Проверить адаптив (узкое окно) и клавиатуру (Tab/Enter по ключевым действиям).
