# ADR 0005 — Автосохранение партии за интерфейсом GameStorage

- Статус: accepted
- Дата: 2026-06-17

## Контекст

Заказчик попросил не терять партию при перезагрузке. Нужно хранилище, но так, чтобы потом
можно было заменить на сервер без переписывания.

## Решение

Интерфейс `GameStorage { save(state); load(); clear() }`. Реализация на `localStorage` с
версионированным ключом. `LocalTransport` вызывает `save` после каждого значимого действия;
при старте делаем `load` и восстанавливаем партию; «Новая игра» делает `clear`. Повреждённые
данные → безопасный фолбэк на новую игру.

## Альтернативы

- Без сохранения (как в старой версии): не отвечает требованию заказчика — отклонено.
- IndexedDB: избыточно для одного небольшого объекта состояния — отклонено.

## Последствия

- ➕ Перезагрузка не теряет игру; код хранилища изолирован, заменяем на сервер позже.
- ➖ Версионирование ключа и фолбэк на повреждённые данные нужно поддерживать (мелочь).
