# ADR 0002 — Стек: React Three Fiber + Rapier + Howler + Vite/TS

- Статус: accepted
- Дата: 2026-06-17

## Контекст

Нужен красивый «дорогой» веб-Yahtzee: 3D-кости с физикой, премиум-визуал, сочность, звук,
адаптивный UI с состояниями, задел под сеть. Ядро игры должно быть отделено от отрисовки и
звука.

## Решение

TypeScript + Vite; UI на React; 3D на Three.js через React Three Fiber (R3F) + drei;
физика — Rapier (`@react-three/rapier`); звук — Howler за интерфейсом `SoundEngine`;
состояние-мост — Zustand; тесты — Vitest. Выбран заказчиком как «Вариант B».

## Альтернативы

- **Vanilla Three.js + Rapier + Howler (Вариант A):** максимум контроля, легче, но больше
  ручного кода для UI/состояний; premium-эффекты пишем сами.
- **Babylon.js (Вариант C):** всё-в-одном, мощная физика, но тяжелее, меньше готовых
  «дизайнерских» примеров под стиль Auros, UI всё равно поверх — избыточно для не-AAA.

## Последствия

- ➕ Премиум-эффекты (drei: тени/окружение/постобработка) и сочность — быстрее.
- ➕ Чистый адаптивный UI и состояния экранов на React; ядро остаётся отдельным TS-модулем.
- ➖ React добавляет вес и уровень абстракции; нужно беречь fps (3D-стейт вне React-рендера).
