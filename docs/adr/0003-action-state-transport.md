# ADR 0003 — Контракт Transport (действие/состояние) как точка под сеть

- Статус: accepted
- Дата: 2026-06-17

## Контекст

Сейчас игра локальная (hotseat), но сеть нужна потом — без переписывания ядра. Нужна явная
точка расширения и контракт, через который UI/слои общаются с игрой.

## Решение

Вводим интерфейс `Transport { getState; dispatch(action); subscribe(cb) }`. UI шлёт только
`Action`, читает только `GameState` + доменные события. Сейчас работает `LocalTransport`
(синхронно прогоняет `reduce` ядра, сохраняет через `GameStorage`). `NetworkTransport` —
пустой класс-заглушка с TODO «точка под сервер», реализуется в Вехе 2.

Заранее закладываем в `GameState` поля под сеть: `gameId?`, `seed` (общий RNG), `players[].id`
— чтобы потом расширять патчем без миграции.

## Альтернативы

- UI напрямую дёргает ядро: проще сейчас, но сеть потом потребует переписать связи — отклонено.
- Сразу писать сетевой слой: противоречит брифу (сеть только заглушкой) — отклонено.

## Последствия

- ➕ Сеть подключается заменой реализации `Transport`, ядро/UI не трогаем.
- ➕ Доменные события дают чистую развязку звука/сочности от логики.
- ➖ Небольшой оверхед абстракции сейчас (оправдан заделом под сеть).
