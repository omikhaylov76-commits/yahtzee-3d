# ADR 0010 — Отключения, пауза «ждём игрока» и реконнект

- Статус: accepted
- Дата: 2026-06-18

## Контекст

Сетевая игра между людьми с разных устройств (часто мобильный интернет) → обрывы связи
неизбежны. Нужно понятное поведение, не ломающее партию, и без потери места игрока. Сервер
авторитетный и держит состояние комнаты в памяти (ADR-0009), поэтому место игрока сохраняется.

## Решение

- **Обрыв связи:** место игрока в комнате сохраняется. Остальным показываем оверлей
  **«ждём {имя}…»**, партия встаёт на паузу (особенно если был его ход). Запускается таймер
  реконнекта (ориентир 60–120 сек, уточним при реализации).
- **Возврат:** игрок перезаходит по той же ссылке / из своего кабинета (по токену сессии для
  зарегистрированных; гость — по коду комнаты), **получает актуальное состояние** и
  продолжает с того же места.
- **Не вернулся за таймаут:** хозяин/остальные могут **продолжить без него** (его ходы
  пропускаются/место освобождается) либо **завершить** партию. Поведение мягкое, без краша.
- **Задел на Веху 3:** точку «кто играет за это место» закладываем так, чтобы вместо
  вышедшего смог доиграть **ИИ-игрок (3.3)**. В Вехе 2 — только «ждём / убрать / завершить»,
  ИИ не реализуем.

### Арбитраж и токены (правки по аудиту — без них гонки/угон места)

- **Таймер реконнекта живёт на СЕРВЕРЕ** (не у клиента-хозяина — он сам может отвалиться).
  Переход состояния места `connected → waiting → dropped` — атомарный, выполняется один раз.
- **Команды «продолжить без него»/«кик» — идемпотентны** (два игрока нажали → одна обработка).
  Решение об освобождении места принимает только сервер по своему таймеру; гонка «вернулся ровно в
  таймаут» разрешается атомарно (либо реконнект успел, либо место освобождено).
- **Секретный реконнект-токен на МЕСТО** (и для гостя тоже!) — НЕ «по коду комнаты»: иначе любой со
  ссылкой займёт место ушедшего. Двойной реконнект одного места: новое соединение вытесняет старое
  («вы подключились в другом окне»).
- **Наследование хозяина:** ушёл хозяин → хозяином становится следующий по списку подключённых
  (иначе пауза «ждём хозяина» зависает навсегда).
- **«Комната исчезла» — протокольный ответ.** Реконнект к неизвестной/истёкшей комнате (в т.ч. после
  деплоя/рестарта, состояние в памяти) → сервер отвечает `room-not-found`/`expired`, клиент
  показывает «партия завершена», а не вечную загрузку (ADR-0013).
- **Выбывший на своём ходу** — поведение пропуска хода определено в ADR-0009 (чтобы `game:over`
  гарантированно наступал).

## Альтернативы

- **Мгновенно выкидывать отключившегося:** просто, но рушит дружескую партию из-за секундного
  обрыва мобильной сети — отклонено.
- **Ждать бесконечно:** партия зависает навсегда из-за одного ушедшего — отклонено (нужен
  таймаут + выход для остальных).

## Последствия

- ➕ Секундные обрывы не ломают игру; возврат бесшовный.
- ➕ Партия не «висит» вечно из-за одного игрока.
- ➕ Готовая точка под AI-замену в Вехе 3.
- ➖ Нужна модель «сессия игрока ↔ место в комнате» и токены реконнекта.
- ➖ Состояние в памяти: при рестарте сервера активные партии всё равно теряются (см. ADR-0009).
