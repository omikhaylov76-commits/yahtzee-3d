# Yahtzee 3D — правила проекта (индекс)

> Это индекс правил для работы над проектом. Статус и этапы живут в docs/roadmap.md и docs/progress/.

## О проекте

Красивая 3D-игра в кости Yahtzee для веба. Локальная игра 1–4 игрока (hotseat),
с заделом под сетевую игру в будущем. Приоритеты: визуал «дорого» и звук.

- **Язык интерфейса:** английский (Roll, Yahtzee, Full House, …).
- **Запуск:** локально в браузере сейчас; публикация в интернет — заложить на будущее,
  без лишней работы на старте.

## Стек

TypeScript + Vite. UI — React. 3D — Three.js через React Three Fiber (R3F) + drei.
Физика — Rapier (`@react-three/rapier`). Звук — Howler (за интерфейсом `SoundEngine`).
Состояние-мост — Zustand. Хранилище — localStorage (за `GameStorage`). Тесты — Vitest.
Линт/формат — ESLint + Prettier. Подробности и причины — `docs/architecture.md`, ADR 0002–0005.

## Команды

> Точные скрипты зафиксируются при сборке скелета (F0); ориентир:

- Запуск (dev): `npm run dev`
- Сборка: `npm run build`
- Линт: `npm run lint`
- Тесты: `npm run test`

## Конвенции

- Архитектура слоями: **ядро игры (правила/счёт)** отдельно от **отрисовки 3D** и от
  **звука**; общение через явные контракты/события, не напрямую.
- Сеть — за абстракцией транспорта (интерфейс), сейчас только заглушка-заглушка; ядро
  не знает, локальная игра или сетевая.
- Тексты интерфейса — на английском; строки не «зашиты» вперемешку с логикой (задел под
  локализацию, но без оверинжиниринга).
- Код в едином стиле модуля; имена осмысленные; без «причешу заодно» вне текущей фичи.
- Ассеты (звуки, текстуры) — только со свободной лицензией; источник фиксируем в docs.

## Чего нельзя

- Не копировать код старой версии (`~/Desktop/vibecoding/yahtzee`) — она только справка
  по правилам Yahtzee и подсчёту очков.
- Не писать сейчас рабочий сетевой код — только архитектурную заглушку за контрактом.
- Не лезть в ядро игры из слоя отрисовки/звука напрямую (только через контракт).
- Секреты — никогда в коде; пользовательский ввод (имена игроков) экранировать (XSS).
- Не добавлять зависимости без согласования с заказчиком.
